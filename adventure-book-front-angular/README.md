# Adventure Books - Angular frontend

Frontend Angular 18.1.3 para a API Spring Boot do projeto Adventure Book.

## Requisitos

- Node.js 20.11 ou superior (recomendado Node 20 LTS)
- npm
- Backend Spring Boot em execução

## Executar

1. Extrai o ZIP.
2. Abre um terminal na pasta `adventure-frontend`.
3. Instala as dependências:

   ```bash
   npm install
   ```

4. Confirma o endereço da API em `src/environments/environment.ts`:

   ```ts
   apiUrl: 'http://localhost:8080'
   ```

5. Inicia o Angular:

   ```bash
   npm start
   ```

6. Abre http://localhost:4200.
